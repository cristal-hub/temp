# KNOWN LIMITATIONS — известные ограничения интеграции

1. **Pre-existing FAIL/ERROR Samsung не устранялись (вне scope).** Полный
   pytest Samsung содержит 74 FAILED и 1 collection error
   (`test_execution.py`, корневой файл — `FileNotFoundError`) ДО интеграции.
   Этот набор побайтово идентичен в baseline и final (сравнение по точным
   именам — пустой diff). B2-интеграция не создавала и не скрывала ни одного
   падения; устранение pre-existing дефектов — отдельная задача вне данного ТЗ.

2. **Окружение песочницы.** Реальные SDK (`t_tech.invest`,
   `pandas_ta_classic`, `python-telegram-bot`) в среде прогонов отсутствуют;
   `conftest.py` автоматически ставит заглушки (механизм самого Samsung,
   поведение не менялось). Прогоны и baseline, и final выполнены в ОДНОЙ
   среде (Python 3.12.16, pytest 9.0.2), поэтому сравнение корректно.

3. **Семантика времени закрытия.** Используемый API-контур
   (`get_sandbox_order_state`) не возвращает подтверждённого времени
   исполнения сделки: в CSV сохраняется время ЗАПРОСА SELL
   (`close_requested_at`/`requested_at` cursor'а) как ЯВНО обозначенный
   детерминированный proxy времени закрытия. Время исполнения не
   изобретается; подмена на `updated_at_utc`/`timestamp_utc`/`datetime.now()`
   исключена. Семантика унаследована от v5–v7 без изменений.

4. **Состав папки.** Папка = полное рабочее дерево Samsung `051b10f` с
   интегрированными файлами и B2-тестами, БЕЗ служебных каталогов `.git`,
   `__pycache__`, `.pytest_cache`. Runtime-файлы (`state.json`,
   `order_ledger.jsonl`, `research_trades.csv`, `research_events.jsonl`,
   `sandbox_pnl.csv`) включены в ИСХОДНОМ виде Samsung (прогонами pytest не
   изменялись — проверено diff-ом и SHA256).

5. **Запуск без Samsung-репозитория.** Папка самодостаточна для pytest
   (включает conftest.py, tests/, requirements.txt). Для производственного
   запуска робота по-прежнему требуется окружение из `requirements.txt` и
   `.env` пользователя (не входит в пакет — секретов в архиве нет).

6. **Вне-scope дефекты.** В ходе интеграции новых дефектов вне scope не
   обнаружено; сообщения об ошибках вне scope не требовались.

7. **Границы изменений.** Исправлены только области, необходимые B2 v1–v7
   (учёт собственного закрытия, CSV-recovery, целостность timestamp,
   идентичность recovery/cursor'ов). Стратегия, сигналы, фильтры, пороги,
   BUY-цепочка, SL/TP, RiskManager, screener, отправка заявок, B3 — не
   изменялись (побайтовое доказательство в SHA256SUMS.txt / FULL_DIFF.patch).
